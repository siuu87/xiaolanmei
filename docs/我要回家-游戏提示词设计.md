# 一、世界观与开场情境

## 1.1 世界
当代中国一座普通地级市。没有超自然元素，没有科幻，没有巧合救场。
所有后果都遵循现实物理与中国现行交通法规。运气存在，但运气只决定"什么时候出事"，不决定"会不会出事"。

## 1.2 时间与地点
- 时间：周五 20:00 入席，21:00 起为可玩时间，游戏最长推进到次日 08:00。
- 地点起点：城南"老灶台"饭店，二楼 208 包间。
- 终点：城西家中，距离 12 公里。途经：城南老灶台 → 江州大道 → 跨江大桥 → 城西住宅区。
- 天气：深秋，小雨刚停，路面湿滑反光，气温 9℃。夜里有薄雾。

## 1.3 主角（玩家）设定
- 我，男，32 岁，市政设计院画图员，驾龄 6 年，体重 70kg。
- 开一辆灰色朗逸，停在饭店楼下地库 B1，车位 C-17。
- 妻子怀孕 7 个月，在家等门。明天上午 9:00 要交一份图纸。
- 性格：不太好意思拒绝人，但心里有数。这就是今晚全部矛盾。

## 1.4 在场人物（固定，不得随意增减）
- 老王，48 岁，项目包工头，今晚做东。爱劝酒，把"喝不喝"和"给不给面子"绑在一起。他自己开了车来，也喝了。
- 小李，26 岁，同事。今晚滴酒未沾，因为他要开车去接女朋友。全场唯一的清醒人。
- 老张，39 岁，老同学。骑一辆改装过的电动车来（车身加长、提速改装、脚踏板是装饰件）——这辆车经鉴定属于机动车，玩家一开始不知道。
- 小周，服务员，20 岁出头，只负责上菜和叫车。

## 1.5 开场冲突（一句话）
我得回家，妻子在家，明早要交图；但做东的是甲方关系，酒杯已经举到我面前了。

# 二、第一人称文风定义（全程强制）

1. **人称**：只用"我"。现在时。禁止第二人称"你"指玩家，禁止上帝视角。
2. **句长**：以短句为主，单句不超过 25 字；每段 3-6 句；每屏正文 80-150 字。
3. **感官优先**：写气味（白酒的甜、雨后的沥青、车里的皮革味）、温度（手背的凉、酒下肚的热）、声音（杯底磕桌、雨刷、耳鸣）、触觉（钥匙的齿、方向盘的包浆）。用感官代替心理分析。
4. **禁止心理说明书**：不许写"我感到很纠结""我内心十分挣扎"。要写"我把杯子端起来，又放下，又端起来"。
5. **数字要具体**：12 公里、22:47、C-17、手机电量 17%、第 3 杯。具体数字让虚构变可信。
6. **禁止**：成语堆砌、排比煽情、网络流行梗、感叹号连用、道德评论、作者旁白。
7. **内心独白**：偶尔使用，用直角引号「」包裹，每屏不超过 1 次，不超过 15 字。
8. **留白**：结尾句要留一个未完成的动作或声音，不要总结。

# 三、核心机制：「视角模糊」——醉酒状态怎么写

## 3.1 总则
主角饮酒后，**所有**场景正文与**所有**选项文案都必须体现醉态。
禁止在醉酒段落里用清醒时的清晰叙事，禁止写"我喝醉了，所以我判断力下降"这类解释——
你要让**文字本身**变糊，而不是告诉读者它糊了。

## 3.2 三档定义

清醒度档位由 BAC（见第五节）自动决定，共三档：

| 档位 | 代号 | BAC 区间（mg/100ml） | 现实对应 |
|---|---|---|---|
| 清醒 | SO=0 | < 20 | 未达饮酒驾驶标准 |
| 微醺 | SO=1 | 20 ~ 79 | 已达「饮酒驾驶」标准 |
| 大醉 | SO=2 | ≥ 80 | 已达「醉酒驾驶」标准 |

## 3.3 清醒档（SO=0）写法
- 句子完整，主谓宾齐全，逻辑链清晰。
- 能准确读出时间、路牌、里程、仪表盘、手机电量。
- 选项 4 个，文案明确、语法完整，含明确的利弊信息。
- 每屏允许出现 1 次理性分析（"老王喝了三杯，他不能开车"）。

## 3.4 微醺档（SO=1）写法
**正文规则（五选三，每屏至少命中 3 条）**
1. 句子变长、开始跑题：一句话里塞进两个不相干的信息。
2. 感官错位一处：声音延迟半拍、灯光拉丝、地面轻微起伏、别人的脸有重影。
3. 重复确认一次：同一个信息写两遍（"我再看一眼——还是那条路"）。
4. 数字模糊化：禁止给出精确数字，改为"大概""好像""十点？不对，应该是十一点"。
5. 身体失去精确控制：手滑、钥匙掉了两次、杯子端不平、说话打磕巴。
**选项规则（全部强制）**
- 选项从 4 个减为 **3 个**：判断力下降，最优选项从视野里消失。
- 选项文案口语化、可省略主语、允许一个错别字或半句话（"就……就一小段，没事的"）。
- 必须包含 1 个"听起来很合理但实际有风险"的选项。
- **禁止**在选项里出现精确里程、时间、法律后果等理性信息。

## 3.5 大醉档（SO=2）写法
**正文规则（全部强制）**
1. 主语和谓语可以缺失，允许只有名词和动词的碎片句。
2. 大量使用省略号与破折号（每屏不少于 3 处）。
3. 词序打乱、自我更正："灯，红灯——不，绿的。绿的吧。"
4. 时间感断裂：段落之间直接跳切，用"……"连接，不交代中间发生了什么。
5. 感知夸张：耳鸣、地面像船、所有人的脸长成同一张脸、声音从很远的地方传来。
6. **禁止**给出任何精确的客观信息——不得确认时间、距离、车牌、对方说了什么原话。
**选项规则（全部强制）**
- 选项只剩 **2 个**。
- 选项文案极短（≤12 字），含糊、带重复字或结巴（"开……开回家"/"睡，睡一会儿"/"不、不喝"）。
- 允许出现 1 个"幻觉选项"：它看似是眼前的事，实际是一段记忆闪回。玩家选中后，不推进剧情，只消耗 10 分钟，并用一句"我刚才在想什么"把玩家拉回原节点。
- **禁止**任何理性分析型表述，禁止出现"安全""危险""违法"这类判断词。

## 3.6 档位切换的写法
- 从清醒升到微醺：不要宣告，用一句生理变化带过（"第三杯下去，耳朵里开始有嗡嗡声"）。
- 从微醺升到大醉：用一次感官断裂（"老王的脸忽然变成了两个人，又合回一个"）。
- 从高降到低（等待、喝水、呕吐、睡过之后）：文字要**突然变清楚**，并用一句提示落差——
  "世界一下子清楚了。清楚得让人难受。"
  这句话固定为回落提示语，每次档位下降时出现（可微调措辞，语义不变）。

## 3.7 呈现层建议（给开发者，可选实现）
- 微醺档：正文 CSS 加 0.6px 文字模糊 + 1° 缓慢摇摆动画；选项按钮顺序随机打乱。
- 大醉档：正文加文字重影（双层 text-shadow）、行高轻微抖动、行序随机错开；选项需长按 0.8 秒或二次确认才能选中。
- 清醒档：全部取消特效，形成强烈对比。

## 3.8 硬性禁令（醉酒段落）
- 不得出现"酒精""BAC""血液酒精浓度""醉驾""酒驾"等术语（后果只在结局页说）。
- 不得在醉酒段落做任何法律科普或安全提示。
- 不得美化醉酒——不得写成"畅快""豪迈""兄弟情深"，只写失控。
- 不得让玩家在醉酒状态下获得任何清醒时得不到的好处。

# 四、玩家状态变量

| 变量 | 代号 | 初值 | 说明 |
|---|---|---|---|
| 饮酒量 | U（标准杯） | 0 | 1 杯 = 啤酒 350ml / 白酒 50ml(52°) / 红酒 150ml |
| 血液酒精浓度 | BAC | 0 | 结算量，玩家不可见，只在结局页揭示 |
| 清醒度档位 | SO | 0 | 由 BAC 映射：0/1/2 |
| 时间 | T | 21:00 | 每推进一个节点按表 +N 分钟 |
| 警觉度 | A | 100 | 影响被发现概率与危险识别，0-100 |
| 交通方式 | M | 未定 | 步行/自驾/代驾/电动车/出租/留宿 |
| 头盔 | H | 无 | 无 / 戴了没系扣 / 戴好系扣 |
| 路线 | R | 未定 | 大路（临检概率高、事故低）/ 小路（临检低、事故高）/ 逆行或机动车道 |
| 车辆属性 | V | 超标改装电动车 | 隐藏变量，出事后才揭示 |
| 驾照 | DL | 有效 | 有效/暂扣/吊销 |
| 案底 | CR | 无 | 无/危险驾驶罪/交通肇事罪 |
| 身体 | HP | 完好 | 完好/擦伤/骨折/重伤/死亡 |
| 关心值 | C | 0 | 是否劝阻他人、是否帮他人叫车，影响隐藏结局 E5 |
| 安全积分 | S | 100 | 仅用于结局页评分展示，不改变剧情路径 |

**结算公式**（每节点结算一次，向下取整）
```

BAC = max(0, U × 15 − 已过分钟数 × 0.25)  
A   = clamp(0, 100 − BAC × 0.8 − 疲劳值(每小时 +5) + 补正)

```
补正：喝浓茶/咖啡 +5；吐过 +10；睡满 4 小时 −全部酒精清零但疲劳 +20。

**档位映射**
```

BAC < 20        → SO=0 清醒  
20 ≤ BAC < 80   → SO=1 微醺  
BAC ≥ 80        → SO=2 大醉

```

# 五、完整分支树

> 图例：▸ 分支点（含用户指定的 4 个：B1/B2/B3/B4）｜◇ 次级分支｜○ 事件判定｜★ 结局

## N0 开场（21:00，208 包间）
菜过五味，老王起身，端着杯子走到我面前。
→ N1

## ▸ N1｜B1 分支点：喝，还是不喝（21:00）
- **喝** → N2
- **不喝** → N1-B

### ◇ N1-B 挡酒方式（不喝路径）
- 说明"我开了车" → 老王："车放着，明天再取"（挡住成功率 70%，失败则进入 N2，U 从 2 起）
- 说明"我爱人怀孕七个月，在家等我" → 挡住成功率 90%（老王自己有女儿）
- 以茶代酒硬扛，不解释 → 挡住成功率 50%，失败则进入 N2，U 从 3 起
- **挡住** → 进入 N1-C
- **没挡住** → 进入 N2

### ◇ N1-C 不喝的后续（21:40 可提前离场）
- 提前离场（21:40 走） → ○ N1-C1：清醒自驾 → **E1 安全到家**（路上可插入一次临检，吹气 0，放行）
- 留下陪到散场（23:00 走） → ○ N1-C1：清醒自驾 → **E1**（疲劳值 +10，路上可能遇到被醉驾司机追尾事件，判定 15%，若触发 → **E5 被动受害**，可捡回 E1）
- 顺手帮老张叫了车 / 劝住老王别开车 → C +1 → 解锁隐藏结局 **E6 同饮者连带责任** 的豁免，结局页额外一句肯定

## ▸ N2｜喝多少（21:00-21:20）
- **浅尝，一杯啤酒** → U=1（BAC 15，仍清醒，临界）
- **陪着喝，三杯啤酒** → U=3（BAC 45，微醺）
- **硬扛到底，三杯白酒 + 两瓶啤酒** → U=7（BAC 105，大醉）

### ◇ N2-A 老王加码（"最后一杯，必须干"）
- 接受 → U +2
- 挡回去 → U 不变，C +1
→ 进入 N2-B

### ◇ N2-B 散场时刻（21:00 起，随 U 增大而推后）
- U ≤ 1 → 22:10 散场
- U = 3 → 22:40 散场
- U ≥ 5 → 23:30 散场
→ 若 U ≥ 6 且 T ≥ 23:00 → 先进入 **N2-S 特殊节点**
→ 否则进入 N3

### ◇ N2-S 特殊节点：大醉后的"要不要先睡"（仅 U≥6 触发，SO=2 写法）
- **在车里睡一觉，天亮再走** → 睡到次日 07:00（BAC 清零，疲劳 +20）→ N2-S2
  - N2-S2：打车回家 → **E1 安全到家**（迟到版）
  - N2-S2：发动车自己开回去（"我睡了一整夜，肯定没事"）→ **E11 隐藏结局：隔夜酒**
- **硬撑着走** → N3
- **在饭店开房住下** → **E1 安全到家**（留宿版，扣分最少）

## ▸ N3｜B2 分支点：开车，还是骑电动车（散场后，饭店门口）
老王把一串钥匙塞进我手里："我那辆电动车停后门，你骑回去，明早还我。"
（那辆车的真实属性为隐藏变量 V：超标改装电动车，经鉴定属机动车）
- **走向地库，去开车** → N4
- **接钥匙，去后门骑电动车** → N5
- （仅 SO=0 时可见第三个选项）**把车留下，打车走** → **E1 安全到家**

## ▸ N4｜B3 分支点：自己开，还是找代驾（地库 B1，C-17）
- **自己开** → N4-A
- **找代驾** → N4-B

### ◇ N4-A 自己开：走哪条路
- **江州大道（大路，有路灯有监控，慢 8 分钟）** → 临检遭遇概率 60%，事故概率 ×1.0
- **沿江老路（小路，黑，快 8 分钟）** → 临检遭遇概率 15%，事故概率 ×1.6
- （大醉档下两个选项文案须含糊化）→ ○ N4-A1

### ○ N4-A1 路上事件（按概率依次判定）
1. 先判**事故**：事故概率 P = 基础 8% × 路线系数 × (SO=1 时 ×2.5，SO=2 时 ×5)
   - 触发 → **E9 车祸**
2. 未出事故，再判**临检点**：
   - 未遇到 → **E2 侥幸到家**
   - 遇到 → ◇ N4-A2

### ◇ N4-A2 临检反应（三选一，按 SO 档位决定呈现清晰度）
- **停车，配合吹气** → 按 BAC 判定：
  - 20 ≤ BAC < 80 → **E7 饮酒驾驶被查**
  - BAC ≥ 80 → **E8 醉驾入刑**
- **掉头就走** → 民警追截 → **E10 冲卡逃逸**
- **踩油门冲过去** → **E10 冲卡逃逸**（加重版）

### ◇ N4-B 找代驾：找哪一种
- **平台代驾（叫了要等 25 分钟）** → 等待期间 BAC 下降 6 → ○ 判定：
  - 95% → **E1 安全到家**（最优路径）
  - 5%（代驾剐蹭/坐地起价扯皮） → **E4 代驾的代价**（人安全，折腾到凌晨两点）
- **门口的黑代驾（不用等，150 块不走表）** → ○ 判定：
  - 60% → 上车后发现他身上也有酒气，一路险象环生 → **E4 代驾的代价**（惊险版）
  - 40% → 顺利到家 → **E1 安全到家**（但要写明：这一次是运气）
- **让小李送我（他没喝，但他只有 C1，且他女朋友还在等他）** → **E1 安全到家**（人情版：车明早取，你欠小李一顿饭）

## ▸ N5｜B4 分支点：戴头盔，还是不戴（饭店后门车棚）
车把上挂着一顶旧头盔，蓝色，带子还在。
- **戴上** → ◇ N5-A
- **不戴**（嫌闷/嫌丑/就三公里） → ◇ N5-B

### ◇ N5-A 戴了头盔：系不系扣
- **系好下巴扣** → 头盔防护生效（重伤概率 ×0.25）
- **只是扣上，扣很松/干脆不系** → 防护打折（重伤概率 ×0.6，摔倒时头盔会先飞出去）
→ N5-C

### ◇ N5-B 不戴头盔
→ 重伤概率 ×1.0 → N5-C

### ◇ N5-C 走哪条道
- **走非机动车道，慢一点（多 12 分钟）** → 事故概率 ×1.0
- **借机动车道抄近路** → 事故概率 ×1.8，临检遭遇概率 40%
- **逆行，省一整个路口** → 事故概率 ×2.2
→ ○ N5-D

### ○ N5-D 电动车事件（按概率判定，单项触发即结束）
1. **大货车右转内轮差**（走机动车道或逆行时概率最高）→ 判头盔：
   - 系好扣 → **E3 有惊无险**
   - 未系扣/未戴 → **E12 颅脑损伤**
2. **路面坑洼 + 湿滑摔倒** → 判头盔：
   - 系好扣 → **E3 有惊无险**（膝盖擦破，头盔裂一道缝）
   - 未系扣/未戴 → **E12 颅脑损伤**
3. **路口夜查非机动车** → 呼气检测：
   - BAC < 80 → 警告或 5-50 元罚款，放行 → **E3 有惊无险**
   - BAC ≥ 80 → 登记，且该车被暂扣待鉴定 → 揭示隐藏变量 V → **E13 隐藏结局：超标车等于机动车**
4. **路边违停轿车突然开门** → 同 1 判定

## C.2 关键设计取舍

1. **为什么"骑电动车"的选项由老王递钥匙给出**：主角开车来饭局，若要"开车/骑电动车"二选一同时成立，必须外借一辆车。借来的车同时是隐藏变量 V（超标改装车），让 E13 的揭示有物理依据，而不是凭空普法。
2. **为什么加了"戴了头盔但没系扣"**：这是现实中最高频的错误，也是最容易用文字表现的细节（摔倒时头盔先飞出去）。它让 B4 不只是二选一，而是有真实梯度。
3. **为什么"侥幸到家"是伪好结局**：如果自己开车没出事就给满分，游戏的教育意义就归零。E2 强制在结尾追加"第二天"的追责电话——现实中监控与举报确实可以事后追责。
4. **为什么醉酒段落禁止法律术语**：一旦在沉浸段落里普法，文本立刻变成宣传册。所有法律信息被隔离在结局页的"事后笔记"里，用事实而非口号。
5. **BAC 模型的简化**：`U×15 − 分钟×0.25` 是对 70kg 成年男性的粗略拟合，精度足够支撑三档分级，但不宣称医学准确；E11 隔夜酒结局专门用来说明"模型之外还有个体差异"。

## C.3 待复核确认的风险点

- E8 中关于 80–150mg/100ml 的处理引用了 2023 年 12 月两高两部《关于办理醉酒危险驾驶刑事案件的意见》的情节显著轻微条款，建议在交付前由复核人确认口径与表述，避免被误读为"喝到 150 就没事"。
- 各地电动自行车头盔罚则不一（多为 20–50 元），结局页统一表述为"按当地规定处以警告或罚款"，不写死金额。
- 超标电动车的鉴定标准在不同地区判例存在差异，E13 的措辞留了"经鉴定"的余地。
